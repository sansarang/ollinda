# 2026-08-06 노출 역설계 — 검증 기록과 이후 관측 기준

> 이 문서는 **이후 발행 글이 어떻게 되는지 계속 보기 위한 기준선**이다.
> 오늘 무엇을 확인했고 무엇을 못 했는지가 여기 있어야, 다음 관측이 비교 가능해진다.

## 1. 오늘 확인한 것

### 증명된 것 (하나)
**꾸준한 발행(C-RANK)은 필요조건이 아니다.**
같은 검색 화면 상위에서 월 3.5건 채널과 월 63.8건 채널이 나란히 떴다(18배 차이).
근거: 공개 RSS의 최근 글 발행 간격 실측.

### 소거된 것 — 다만 **"남의 글 표면에서는 안 보인다"**로 읽어야 한다
| 축 | 방법 | 결과 |
|---|---|---|
| 장소 신호(지도·주소·전화·예약) | 뽑힘/안뽑힘 대조 | 역방향 경향, 유의차 없음 |
| 문서 구조화(표·목록·FAQ·영상) | 7업종 정독 | 업종마다 방향 엇갈림 |
| 의미 층위(질의 적합도·실경험·홍보성) | LLM 판정 | 3업종 전부 동일값 |
| 순위 단조성(공감·댓글·발행경과) | Spearman | 교차 공통 인자 0 (표본 얇음) |

**★ 한계**: 표본이 전부 **남의 업체**다. 남의 글은 결과만 보이고 원인(유입·광고·관계)은 안 보인다.
원인이 글 밖에 있다면 표면을 아무리 재도 안 나오는 게 당연하다.
→ **"글 안에 답이 없다"가 아니라 "이 방법으로는 못 본다"가 정확하다.**

### 밟은 함정 (재발 방지)
1. **자기 글 습관 오염** — 썬팅 표본에서 `표 2 vs 0`, `FAQ 있음/없음`이 인자로 보였다.
   7업종 확인하니 FAQ는 전부 0이었다. **우리가 만든 글의 습관이었다.**
   → `coexpose/scope.py`가 썬팅·중고차를 수집 단계에서 차단.
2. **수집 절차의 흔적** — `at`(수집 시각)이 순위와 rho=1.0으로 나왔다.
   1위부터 순서대로 수집했으니 당연하다. → `monotone.EXCLUDE_KEYS`.
3. **대조군 오염 3회** — 동시노출 여부(대조군 없음) → 2페이지 밖(URL 페이징 무효)
   → 같은 채널·같은 주제(채택). 그 안에서도 지역 불일치·업종 불일치를 두 번 더 걸렀다.
4. **계측기 의심** — `answer_fit`이 1·3만 뱉어 자를 검증했다.
   극단 케이스에서 0.0~5.0으로 벌어져 자는 정상, 차이가 진짜 없는 것으로 확인.

## 3. 이후 발행 글 관측 기준

지금부터 발행하는 글은 **다음을 함께 기록**해야 비교가 된다.

- 발행 시각 / 색인까지 걸린 시간
- `/r/` 링크 클릭(사람·봇 분리, 채널별)
- 순위 추적(키워드별, 일자별)
- `botlog`의 크롤 시점 — 크롤과 순위 변화의 선후
- 그 글이 노린 질의가 **비어 있었는지**(아래 4번)

**핵심 질문**: 유입(클릭)이 늘어난 날과 순위가 오른 날이 맞물리는가.
이게 "초기 반응이 순위를 정한다"는 가설을 우리 데이터로 처음 검증하는 길이다.
**남의 업체로는 못 한다 — 루마·주안에서만 가능하다.**

## 4. 다음 방향: 빈 질문 선점

노출 0에서 노출 1을 만드는 유일한 코드 경로.
경쟁이 붙은 키워드가 아니라 **아무도 글로 쓰지 않은 구체 질문**을 찾아 먼저 쓴다.
판정은 하나다 — 그 질문으로 검색해서 답하는 글이 없으면 빈 것이다.
